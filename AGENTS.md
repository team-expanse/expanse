# Models

Two models are available for this project.  Each is described below.

glm-5.3 (provider: opencode) - This model is for planning, design and thinking, not actually writing code.
qwen3.6-moe:35b-a3b (provider: flm) - This model turns the clear, detailed design from glm-5.3 into on-disk files.  It also executes all tests.

The local, flm model only has 32k of context, so keep assigned tasks small.
