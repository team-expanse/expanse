# Expanse

A flexible, deterministic, extendable, expansive Linux-based server infrastructure system.  Based on NixOS, Expanse is more than just another Linux server.  It brings together the best of open source software, methodology, flexibility, and ingenuity.  Expanse is the last Linux server system (it is more than just an OS/distribution) you'll install, at home or at work. Think of Expanse as an equivalent of Legos, but with Linux!

## Features

Expanse offers the following features:
- control plane entirely written in Go and HTMX
- simple to install
- easy clustering (plug and play)
- network-based storage
    - SMB
    - NFS
    - iSCSI
- self-hosted services
    - web
    - database
    - on-prem LLMs (with openapi-compatible access)
- virtualized workloads
- always-redundant architecture (default for all clusters)
    - everything is replicated (real time)
    - everything is load-balanced
    - everything is highly available
    - no single point of failure, anywhere in the cluster
    - any single cluster member can go down at any time with virtually no disruption
- powerful, yet intuitive web management interface
- cloud-based backups and restores
    - not just your data, but also Expanse configs
- lightweight... (from 10+ year-old laptops, to modern, high-performance servers)
    - minimal overhead so your resources are free for your workloads
